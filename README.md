API Automation Homework – User CRUD Operations:

Overview:
This project demonstrates API testing using RestAssured in Java with Maven and TestNG. It focuses on performing CRUD operations (Create, Read, Update, Delete) on the Petstore Swagger API (https://petstore.swagger.io/v2/user).

Prerequisites:
1.Java JDK 8 or higher
2.Maven
3.Eclipse IDE or IntelliJ IDEA
4.Git
5.TestNG

CRUD Operations Implemented:

1.Create – Add a new user
2.Read – Get user information
3.Update – Update user information
4.Delete – Delete a user

How to Run:

1.Run tests using TestNG in Eclipse or any IDE
2.Verify that all tests pass
3.Assertions are used to validate responses
